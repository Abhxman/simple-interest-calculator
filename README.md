# Simple Interest Calculator

## Description
A simple interest calculator that calculates the interest earned or paid on a principal amount over a specified period at a fixed annual interest rate.

## Formula
**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal:** The initial amount of money.
- **Rate:** Annual interest rate in percentage.
- **Time:** Duration in years.

## Example
- Principal: 1000
- Annual Interest Rate: 5%
- Time: 2 years
- Simple Interest: 100
- Total Amount: 1100

## Features
- Calculates simple interest.
- Accepts principal, rate, and time as inputs.
- Displays the interest and total amount.

## Technologies
- Python

## Purpose
This project demonstrates the basic concept of simple interest calculation using a mathematical formula.
